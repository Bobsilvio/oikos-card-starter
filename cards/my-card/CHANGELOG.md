# Changelog — My Card

All notable changes to this card. Format: [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

Rules:
- Write entries in **English** (default language shown in the store).
- One `## [version] - YYYY-MM-DD` section per release (newest on top).
- Below it, `- ...` lines describing what changed (you may group them under `### Added` / `### Changed` / `### Fixed`).
- The version here MUST match the one in `manifest.json`.
- The store shows these entries when a card is opened; entries newer than the installed version are highlighted.
