# Changelog — My Card

Tutte le modifiche rilevanti della card. Formato: [Keep a Changelog](https://keepachangelog.com/it/1.0.0/).

Regole:
- Una sezione `## [versione] - AAAA-MM-GG` per ogni release (la più recente in alto).
- Sotto, righe `- ...` con cosa è cambiato (puoi raggrupparle in `### Added` / `### Changed` / `### Fixed`).
- La versione qui DEVE combaciare con quella in `manifest.json`.
- Lo store mostra queste voci quando si apre la card; quelle più recenti della versione installata vengono evidenziate.
